# **NOTEBOOKS FOLDER**

This folder contains Jupyter notebooks that I used to explore and planify the project. These notebooks include:

- **Detectron 2:** This notebook contains code and experiments related to the Detectron 2 platform, which is used for object detection and segmentation tasks. It includes all the code and experiments I conducted to understand and utilize Detectron 2 for my project.

- **Inpainting:** To explore the inpainting technique, I replicated some of the experiments that `Hugging Face` has done in their `notebooks` repository. This notebook contains code and results related to inpainting, which is a technique used to generate images and fill in missing parts of an image.
